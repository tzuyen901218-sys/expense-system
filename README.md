# v6 財務綜合追蹤系統（試算表版）：更新步驟

這一版的資料表跟之前完全不同，Code.gs 要重貼、重新部署。

## 1. 更新 Apps Script（Google 試算表）
1. 擴充功能 → Apps Script → 全選舊程式碼刪掉 → 貼上這裡的 Code.gs → Ctrl+S
2. 上方函式選 `setup` → 執行（會要求 Google Drive 授權，按允許）。
   試算表會多出四個分頁：計畫建檔與期款撥付、計畫經費科目、員工薪資、廠商請款；
   Google Drive 會多一個「財務追蹤附件」資料夾。
3. 部署 → 管理部署作業 → 鉛筆 → 版本「新版本」→ 部署。網址不變。

舊版的分頁（公司單位、計畫、帳戶、核銷單…）不會被動到，確定不用了再自己刪。

## 2. 更新網頁（GitHub）
把這裡的 index.html 上傳到倉庫覆蓋（檔名一定要是 index.html）。

## 之後怎麼用
- 四種紀錄都在網頁新增；狀態切換、刪除也在網頁操作。
- 直接在試算表改資料也可以（例如改金額、備註），網頁重新整理就看得到。`attachments` 欄位請不要手動改。
- 附件存在 Google Drive「財務追蹤附件」資料夾，只有你的 Google 帳號看得到；網頁預覽與下載是透過程式讀取，不用開分享。
- 刪除紀錄時附件會移到 Drive 垃圾桶（30 天內可救回）。
- 「匯出 Excel」照舊，匯出目前畫面上的全部資料。
- 系統密碼：Apps Script → 專案設定 → 指令碼屬性 → APP_PASSWORD 改掉即可。

## 2026-11-20 更新：關卡修改與編輯
- 列表「關卡 / 狀態」欄改成下拉選單，直接選就存檔。預設關卡：待處理 → 審核中 → 已完成（已撥付/已結算/已付款）→ 退件。
- 要增減關卡：改 Code.gs 最上面的 `STATUS_OPTIONS`，重新部署新版本即可，網頁會自動跟著變。
- 每列多了「編輯」：按下去資料會帶回上方表單，改完按「儲存修改」；「取消編輯」可放棄。編輯不會動到附件和關卡。
- 這次更新 Code.gs 和 index.html 都要換；Code.gs 不用再執行 setup，貼上存檔後直接「部署 → 管理部署作業 → 鉛筆 → 新版本 → 部署」。

## 2026-11-20 更新二：員工薪資區分工讀生 / 專任人員
- 新增薪資時多一個「人員類別」欄位（工讀生 / 專任人員）；列表多一欄「類別」，上方有篩選鈕與各類小計；匯出 Excel 也多一欄。
- 舊資料沒有類別的，一律顯示為「工讀生」，用「編輯」改成專任人員即可。
- 這次 Code.gs 要**重新執行一次 setup**（會在「員工薪資」分頁最右邊補上 staffType 欄位標題，不會動到既有資料），再部署新版本；然後上傳 index.html。

## 2026-11-20 更新三：年度與計畫主持人費
- 四張表新增「年度（民國）」欄位，新增時自動帶入今年，可改；列表第一欄顯示年度；頁首多一個「年度」下拉，切換後四張表、三個 KPI、科目統計都只看該年度；Excel 匯出多「年度」欄。
- 員工薪資「人員類別」多了「計畫主持人」，篩選鈕和小計一起多一個。要再增減類別改 Code.gs 的 `STAFF_TYPES`。
- 舊資料年度是空的，列表顯示「-」，在「全部年度」下看得到；用「編輯」補上年度即可。
- 這次 Code.gs 要**重新執行 setup**（四個分頁最右邊補上 year 欄位標題），再部署新版本；然後上傳 index.html。

## 2026-11-20 更新四：計畫只建一次，期款分開列
- 「計畫建檔與期款撥付」列表改成依**計畫編號**分組：每個計畫只顯示一列（年度、編號、名稱、單位、期程、核定總經費、已列幾期與未撥金額、入帳帳戶），底下縮排列出各期撥款（期別、撥付日、金額、附件、備註、狀態、編輯/刪除）。
- 計畫列上的「＋ 新增期款」：按下後表單只剩期別、金額、日期、備註、附件，計畫資料自動帶入，填完送出即可。
- 計畫列上的「編輯計畫資料」：改名稱、單位、期程、總經費、帳戶、年度，存檔後該計畫**所有期款一起更新**。
- 期款列的「編輯」只改那一期的期別、金額、日期、備註。
- 試算表結構沒變（還是一期一列），所以 Code.gs 貼上後**不用執行 setup**，直接部署新版本；再上傳 index.html。
- 第一次建新計畫仍用上方表單一次填完（含第 1 期）。
