# v6 財務綜合追蹤系統（試算表版）：更新步驟

這一版的資料表跟之前完全不同，Code.gs 要重貼、重新部署。

## 1. 更新 Apps Script（Google 試算表）
1. 擴充功能 → Apps Script → 全選舊程式碼刪掉 → 貼上這裡的 Code.gs → Ctrl+S
2. 上方函式選 `setup` → 執行（會要求 Google Drive 授權，按允許）。
   試算表會多出四個分頁：計畫建檔與期款撥付、計畫經費科目、員工薪資、廠商請款；
   Google Drive 會多一個「財務追蹤附件」資料夾。
3. 部署 → 管理部署作業 → 鉛筆 → 版本「新版本」→ 部署。網址不變。

舊版的分頁（公司單位、計畫、帳戶、核銷單…）不會被動到，確定不用了再自己刪。

## 2. 更新網頁（GitHub）
把這裡的 index.html 上傳到倉庫覆蓋（檔名一定要是 index.html）。

## 之後怎麼用
- 四種紀錄都在網頁新增；狀態切換、刪除也在網頁操作。
- 直接在試算表改資料也可以（例如改金額、備註），網頁重新整理就看得到。`attachments` 欄位請不要手動改。
- 附件存在 Google Drive「財務追蹤附件」資料夾，只有你的 Google 帳號看得到；網頁預覽與下載是透過程式讀取，不用開分享。
- 刪除紀錄時附件會移到 Drive 垃圾桶（30 天內可救回）。
- 「匯出 Excel」照舊，匯出目前畫面上的全部資料。
- 系統密碼：Apps Script → 專案設定 → 指令碼屬性 → APP_PASSWORD 改掉即可。
